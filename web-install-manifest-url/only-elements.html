Intended Use Cases

Expected installresult: success.

Current document, no attributes

Executes:


      <install></install>

Background document, cross-origin manifest with custom id

Executes:


      <install manifest="https://mustjab.github.io/manifest.json"></install>

Background document, cross-origin manifest and manifestId

Executes:


      <install manifest="https://isitchristmas.com/manifest.json" manifestid="https://isitchristmas.com/"></install>

Background document, same-origin manifest has id, manifestId undefined

The manifestId property is optional. Assigning undefined to this nullable WebIDL property converts it to null, so no manifest ID is supplied. Installation can still succeed because the manifest declares a custom id. Expected result: success.

Executes:


      <install id="installUndefinedManifestId" manifest="https://kbhlee2121.github.io/pwa/web-install/manifest.webmanifest"></install>
      <script>
        const install = document.getElementById("installUndefinedManifestId");
        install.manifestId = undefined; // Nullable WebIDL converts this to null.
      </script>

invalid_data Cases: Manifest ID Validation

1 parameter, background document, manifest has no id

Executes:


      <install manifest="https://amandabaker.github.io/pwa/web-install/manifest.webmanifest"></install>

Background document, manifest has no id, manifestId undefined

Assigning undefined to the nullable manifestId property converts it to null, so no manifest ID is supplied. This manifest does not declare a custom id, so the expected installresult value is invalid_data, equivalent to navigator.install() rejecting with DataError.

Executes:


      <install id="installUndefinedManifestIdNoCustomId" manifest="https://isitchristmas.com/manifest.json"></install>
      <script>
        const installWithoutCustomId = document.getElementById("installUndefinedManifestIdNoCustomId");
        installWithoutCustomId.manifestId = undefined; // Nullable WebIDL converts this to null.
      </script>

2 parameters, background document, manifest has id, mismatched manifestId

Executes:


      <install manifest="https://mustjab.github.io/manifest.json" manifestid="mismatched-manifest-id"></install>

2 parameters, background document, manifest has no id, mismatched manifestId

Executes:


      <install manifest="https://amandabaker.github.io/pwa/web-install/manifest.webmanifest" manifestid="mismatched-manifest-id"></install>
