Install element test page

Manifest-first installs!

Requires --enable-features=InstallElement,
OR enabling about://flags/#web-app-install-element,
OR an origin trial header for InstallElement

A test app and debugging tool for the declarative version of the Web Install API, <install> element. See more info in the Explainer.

We'd love to hear your feedback! To share feedback, please create a GitHub issue.
